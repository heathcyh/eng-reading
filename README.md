# 積點樂園（國小版／國中版）

**選擇版本：https://heathcyh.github.io/eng-reading/**

| 版本 | 網址 | 內容 | 點數 |
|---|---|---|---|
| 國小版 | https://heathcyh.github.io/eng-reading/es/ | 小四～小六英文、數學 | 弟弟點數 |
| 國中版 | https://heathcyh.github.io/eng-reading/jh/ | 國一～國三英文、數學、特訓、社會段考複習、自然（七上生物） | 柚子點數 |

兩版各自安裝到手機主畫面（圖示分別標「國小」「國中」），點數分開計算。第一次打開新版本時，會自動把拆版前的舊點數與作答紀錄轉入（舊資料保留不刪）。

**點數兌換 3C 時間**：按上方「🎁 兌換 3C 時間」，輸入要用的點數，App 依 **5 點 = 1 分鐘** 算出可換分鐘數（不足 5 點的零頭不扣），按「確認兌換」才會扣點。所有得點、扣點都有紀錄，可在「📜 得點／扣點紀錄」依日期查詢，或篩選只看得點／扣點。

## 🔄 題組更新（國小版、國中版都有）

每個單元一次只顯示「一組」題目，做完後按 **🔄 更新題組**，就把**做完的題目**換成**沒做過的新題目**（沒做完的題會留著）。可以每個單元分開更新。

| 科目 | 一組 | 換題方式 |
|---|---|---|
| 英文 | 每一級 3 篇 | 理解題＋克漏字都做完的文章，換成這一級沒讀過的新文章 |
| 數學 | 每單元最多 10 題 | 先換題庫裡沒做過的題；題庫用完後，由程式出**新數字的變化題**（無限題） |
| 社會、自然 | 每單元 10 題 | 換題庫裡沒出現過的題；全部做過後改為「重新洗牌」 |

- 新題目答對照樣得點；**已經得過分的題目不會重複給分**（重新洗牌、重做這組都不再計點）。
- 單元列表中，做完的單元下方會出現「🔄 這組做完了，更新…題組」按鈕，不用點進去也能換。
- 英文列表可按「📚 顯示全部」看這一級的所有文章。

## 一、放上網路（免費，只需要做一次）

App 需要放在一個 https 網址上，手機才能安裝。以下用 **GitHub Pages**，免費且不用寫程式。

1. 到 github.com 註冊帳號並登入。
2. 右上角按「＋」→「New repository」，名稱填 `eng-reading`，選 **Public**，按「Create repository」。
3. 在新建立的頁面點「uploading an existing file」，把這個資料夾**裡面的所有檔案和 icons 資料夾**拖進去，再按「Commit changes」。
4. 進入「Settings」→ 左側「Pages」→ Branch 選 `main`、資料夾選 `/ (root)`，按「Save」。
5. 等 1～2 分鐘，網址會是：`https://你的帳號.github.io/eng-reading/`

## 二、安裝到手機

- **Android**：用 **Chrome** 開啟上面的網址 →「⋮」→「加到主畫面」或「安裝應用程式」。
- **iPhone**：用 **Safari** 開啟網址 → 分享按鈕 →「加入主畫面」。

> 不要在 LINE、FB 或 Claude App 的內建瀏覽器裡使用，這些瀏覽器多半不支援語音朗讀。

## 三、更新題目（兩種方式）

### 方式 A：更新網路上的題庫（全部手機都會拿到）

1. 在 GitHub 的專案頁面點 `content.json`（或 `math.json`、`social.json`） → 鉛筆圖示（Edit），或直接上傳新的 `content.json` 覆蓋舊檔。
2. **記得把最上面的 `"version"` 數字加 1**，例如 1 改成 2。
3. 按「Commit changes」。學生下次連網打開 App，就會自動拿到新題目。也可以按 ⚙️ →「檢查題庫更新」立即更新。新文章會標示 **NEW**。

### 方式 B：匯入題庫檔（單台手機，不用上網）

在 App 中按 ⚙️ →「匯入題庫檔（.json）」，選擇題目檔即可。匯入時會自動檢查格式；如果有錯，畫面會顯示錯在哪裡。

> 小技巧：可以直接請 Claude「依照這個格式，幫我出 3 篇國二的新文章，輸出成 JSON」，再用方式 A 或 B 加入。

## 四、題目格式

每篇文章是 `passages` 裡的一個物件：

```json
{
  "id": "g8-4",
  "level": 8,
  "title": "My Favorite Season",
  "zh": "我最喜歡的季節",
  "text": "I like {winter} best.\n第二段從這裡開始……",
  "cloze": [
    { "opts": ["winter", "winters", "cold", "snow"], "exp": "中文解析" }
  ],
  "qs": [
    { "q": "Which season does the writer like best?",
      "opts": ["Winter.", "Summer.", "Spring.", "Fall."],
      "exp": "中文解析" }
  ],
  "dict": { "season": "n. 季節" }
}
```

規則：

- `id`：每篇都要不一樣。用已有的 id 會**覆蓋**那一篇。
- `level`：4＝小四，5＝小五，6＝小六，7＝國一，8＝國二，9＝國三。
- `text`：段落之間用 `\n` 分隔。要挖空做克漏字的字用 `{ }` 包起來。
- `cloze`：照 `{ }` 出現的順序排列，數量必須和 `{ }` 一樣。**`opts` 的第一個選項就是正確答案**，App 顯示時會自動打亂順序。
- `qs`：文意理解題，同樣是**第一個選項為正確答案**。
- `tr`（可省略）：每一句的中文翻譯陣列，順序和句數要與文章相同（App 依句點、問號、驚嘆號切句，Mr. 等縮寫不切）。句數對不上時，App 會自動隱藏翻譯。
- `dict`（可省略）：這篇用到、但總字典沒有的單字翻譯。沒有翻譯的字點下去仍然可以聽發音。總字典放在 `content.json` 最下面的 `"dict"`。

## 五、數學題目格式（math.json）

```json
{
  "version": 2,
  "units": [
    {
      "id": "m5-4",
      "level": 5,
      "title": "時間的計算",
      "key": ["1 小時 = 60 分鐘", "重點可用 [3/4] 顯示分數、x^2 顯示次方"],
      "qs": [
        { "t": "mc", "q": "選擇題題目", "opts": ["正確答案", "錯誤1", "錯誤2", "錯誤3"], "exp": "詳解" },
        { "t": "num", "q": "計算題題目", "ans": "2又1/3", "unit": "公分", "exp": "詳解" }
      ]
    }
  ]
}
```

- `t`：`mc`＝選擇題（第一個選項為正確答案），`num`＝填數字。
- `ans` 可以是整數、小數、分數 `7/12`、帶分數 `2又1/3`、負數 `-3`。學生填等值的答案也算對，例如 0.6 和 3/5；但分數要求約到最簡分數。
- 文字格式：`[a/b]` 顯示直式分數，`x^2` 或 `10^{−4}` 顯示次方，`√{25 × 2}` 顯示根號。
- 更新網路上的題庫後，記得把 `version` 加 1。也可以用 App 的「匯入題庫檔」匯入只含 `units` 的 JSON。

## 六、社會複習格式（social.json）

建議改 `tools/build_social.py` 再執行 `python3 tools/build_social.py` 產生 `social.json`。每個單元：

- `id`、`sub`（地理／歷史）、`no`（左側小標）、`title`、`range`、`star`（true＝段考重點，模擬考預設勾選）
- `key`：重點整理，`[{"h":"小標","pts":["重點，可用 **粗體**"]}]`；`table`（可省略）：表格
- `qs`：選擇題，`opts` 第一個是正確答案
- `cards`（可省略）：問答卡 `{"q":"問題","a":"答案"}`

積點：選擇題首次答對 +10；模擬考每題答對 +5，10 題以上滿分再 +50；錯題本訂正答對 +3。

---

## 七、自然複習格式（science.json）

改 `tools/build_science.py` 再執行 `python3 tools/build_science.py`。格式和社會相同（`key`、`table`、`qs`、`cards`），另外：

- 最上方 `EXAM2` 列出第二次段考的單元 id（目前依學校公告：2-2～3-3，P70～P125）；這些單元會標紅色「★ 二段範圍」，模擬考預設只考這些單元。
- 平時考訂正的原題保存在 `tools/science_quiz_src.json`，每次重建都會合併進去。

新增英文文章：改 `tools/add_passages.py` 再執行，會自動檢查克漏字數量、翻譯句數。
